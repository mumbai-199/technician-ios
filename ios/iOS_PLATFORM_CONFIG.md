# iOS Platform-Specific Configuration

## Platform Details

### Minimum Deployment Target
- **iOS Version**: 14.0
- **Rationale**: Supports 95%+ of active iOS devices

### Supported Architectures
**Device:**
- arm64 (iPhone 6s and later)
- armv7k (Apple Watch)

**Simulator:**
- x86_64 (Intel Mac simulator)
- arm64e (Apple Silicon Mac simulator)

### Swift Version
- **Swift**: 5.5+
- **Compatibility**: LLVM Clang 14.0+

## Build Variants

### Debug
- File: `ios/Flutter/Debug.xcconfig`
- Purpose: Local development and testing
- Optimizations: None
- Size: ~150MB (uncompressed)
- Build Time: ~2-5 minutes

### Profile
- File: `ios/Flutter/Release.xcconfig`
- Purpose: Performance testing
- Optimizations: Moderate
- Size: ~50-60MB (compressed)
- Build Time: ~5-10 minutes

### Release
- Purpose: App Store distribution
- Optimizations: Full
- Size: ~40-50MB (compressed with App Thinning)
- Build Time: ~10-15 minutes

## Troubleshooting Reference

### Common iOS Build Issues

#### Issue: "Code signing failed"
**Solution:**
1. Verify Bundle ID in Xcode
2. Check team ID configured
3. Update provisioning profiles
4. Run `flutter clean` and rebuild

#### Issue: "Pod install failed"
**Solution:**
```bash
cd ios
rm Podfile.lock
pod repo update
pod install
cd ..
flutter pub get
```

#### Issue: "App crashes on launch"
**Solution:**
1. Check console: `flutter run -v`
2. Verify permissions in Info.plist
3. Check plugin compatibility
4. Test on simulator first

#### Issue: "Location permissions not working"
**Solution:**
1. Verify NSLocationWhenInUseUsageDescription in Info.plist
2. Test permission request flow
3. Check iOS Settings > Privacy > Location Services
4. Verify app has permission enabled

## Performance Tips

### Build Time Optimization
1. Use release builds for testing: `flutter run --release`
2. Clean periodically: `flutter clean`
3. Keep pods updated: `pod update`
4. Use modular code splits

### Runtime Optimization
1. Use `--split-per-abi` for distribution
2. Enable App Thinning in Xcode
3. Remove unused resources
4. Optimize image assets

### Memory Optimization
1. Monitor memory usage: Instruments in Xcode
2. Profile with DevTools
3. Dispose resources properly
4. Avoid memory leaks in plugins
